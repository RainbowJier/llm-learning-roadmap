## 目标

简历是敲门砖，不是作品集：**一页纸、数字说话、每个字都为"拿到面试"服务**。

## Step 1: 一页纸结构（技术面版）

```
姓名/联系方式/GitHub·博客链接
─────────────────────────
求职意向: 大模型应用开发工程师(Agent/RAG方向)

技能（每条可被提问验证，不堆名词）
  语言: Python(异步/FastAPI/Pydantic) | Java(工作背景)
  LLM应用: 工业级RAG管线 | LangGraph工作流 | 结构化输出 | Ragas评估
  工程: Docker | Redis | Prometheus/Grafana | 异步高并发

项目一: 校园制度智能问答Agent（独立开发, 2026.X-X）★主项目
  4-6条带数字的bullet(Stage 5-07的模板, 填真实数字)
  链接: GitHub(带动图) + 博客实录

项目二: 智能售后Agent / RAG评估实践（Stage 2-3产出）
  2-3条, 突出不同侧面(检索质量工程 / 容错设计)

经历: 原Java后端工作(X年)——写成资产:
  "X年后端经验: 高并发/缓存/分布式——大模型系统的底座能力"

教育背景
```

**删掉**：自我评价形容词、"精通"、与岗位无关的旧技术罗列、课程设计类项目。

## Step 2: Bullet公式与改写示例

公式：**动作 + 手段 + 数字 + 影响**

```
❌ "使用LangChain搭建了知识库问答系统"
✅ "设计父子文档切分+BM25/向量RRF融合+bge-reranker三级检索管线，
   在自建150条评估集上驱动5轮迭代，Context Recall 62%→91%"

❌ "实现了Agent功能"
✅ "用LangGraph构建意图路由+多条件推理+校验重试环的工作流，
   结构化输出三层防线使解析成功率99.5%，混沌测试5类故障注入零5xx"

❌ "有生产部署经验"
✅ "独立完成Docker化部署与Prometheus监控体系，SLO 99.9%/P95 2.2s@50并发，
   模型分级路由+缓存将单请求成本压至$0.003"
```

**自检**：每条bullet能否扛住三层追问？扛不住的数字要么删要么回去补实验。

## Step 3: 投递策略（2小时）

```
批次化投递（保护真实机会）:
  第1批(Week 12): 5-8家"练手"岗(非梦校目标) → 验证简历转化率
  第2批: 简历迭代后投15家主力目标
  第3批: 内推优先(博客发到技术群后的自然人脉 + 校友/前同事)

渠道优先级: 内推 > Boss直聘(响应快) > 官网 > 猎聘
时间: 工作日上午10-11点投递, 附一句定制化开场
      ("看到贵司XX产品在做Agent方向, 我做过类似闭环, 附博客链接")

转化率健康线: 投递→邀约 ≥ 20%
  低于: 改简历(大概率bullet无数字)或补项目亮点
```

## Step 4: 谈薪与决策（1小时）

```
锚点准备:
  目标岗位行情(20个JD薪资区间中位数)
  你的底牌: 可演示的真用户项目 + 全链路工程能力 + Java后端经验(组合稀缺)

谈法:
  报区间不报点: "期望X-Y, 视整体包裹"
  用具体价值锚定: "我能独立扛起Agent项目从0到上线, 这是简历里500用户验证过的"

Offer对比维度(排你自己的序):
  团队是否真做大模型落地 > 导师水平 > 技术栈 > 薪资 > 品牌
  （第一份大模型工作, 前2项权重应该最高）
```
