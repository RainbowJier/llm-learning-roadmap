## 🚀 快速开始

### 环境设置

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate  # Windows

# 安装必要包
pip install fastapi uvicorn pydantic python-dotenv

# 启动开发服务器
uvicorn main:app --reload
```

### 第一个应用

```python
# main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    return {"Hello": "World"}

# 运行: uvicorn main:app --reload
# 访问: http://localhost:8000
```

## 💡 学习策略

### 核心原则
1. **快速行动** - 不要过度思考，先跑起来
2. **实战优先** - 边学边做，在项目中学习
3. **对标学习** - 用Java知识理解Python
4. **持续测试** - 每个概念都要实现验证

### 时间分配
- 阅读理论: 20% (12小时)
- 跟着教程: 30% (18小时)
- 独立编码: 40% (24小时)
- 项目完成: 10% (6小时)

### 遇到问题怎么办
1. **概念不清** → 查看代码示例
2. **代码出错** → 查看官方文档
3. **还是不行** → 简化问题，分步调试
4. **真的卡住** → 查看参考代码
