## Week 10: 内测启动（12小时）

### 放量节奏

```
Day 1   种子用户5人（朋友，容忍bug，逐条收集）
Day 2   修复种子用户致命问题
Day 3   扩到20人（班级群/室友群，附使用说明）
Day 5   扩到50人（院系群，需要一点运营话术）
```

### 运营最小动作

- 群公告模板：一句话价值+链接+举例3个好问题+"遇到答错请点👎，它会变聪明"
- **自己每天用**：每天真实问10个问题（你就是第一个重度用户）

### 每日站会（跟自己开，5分钟）

```
今日: 新用户__/总用户__ | 提问__次 | 👍率__% | 👎__条
Top痛点: (看bad_case表)
明日修: (最多挑1-2个)
```

## Week 11-12: 反馈闭环迭代（28小时）

### 归因→修复→验证循环（每周至少完整跑2轮）

```
feedback表 👎条目
    ↓ 人工归因（复用Stage 2-06五分类）
CHUNK_ISSUE    → 语料缺/解析坏   → 修爬虫/解析，重建索引
RETRIEVE_MISS  → 有但没召回      → 调chunk参数/加同义词
CLASSIFY_ERR   → 意图路由错      → 加few-shot/边界样本
GEN_ERR        → 检索对但答错    → 改prompt/加引用核验强度
OUT_OF_SCOPE   → 本来就不该答    → 完善拒答库+边界意图
    ↓ 修复后
新增case并入测试集 → 全量回归 → 发版 → tag
```

### 版本演进记录（README的镇宅之宝）

```markdown
| 版本 | 周次 | 主要改动 | 👍率 | 测试集四指标 |
|------|------|---------|------|-------------|
| v0.4 | W9 | 上线版 | 72% | CR84/F89 |
| v0.5 | W10 | +边界意图样本×15; 修OCR表格8份 | 78% | CR87/F91 |
| v0.6 | W11 | +时效性过滤(旧政策); +空教室工具修正 | 83% | CR89/F92 |
| v1.0 | W12 | +多轮对话改写增强; 性能P95 2.2s | 87% | CR91/F93 |
```

### 用户沟通（小而真诚）

- 每次发版在群里说："上周你们踩的坑修了X个，比如'XX问题'现在能答对了"
- 挑1-2位活跃用户做15分钟语音访谈（比10条数据更扎心的问题都在这里）
